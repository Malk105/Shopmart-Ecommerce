
# ShopMart E-commerce

ShopMart is a PHP-based e-commerce website.

## Technologies

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Features

- User Registration
- User Login
- User Logout
- Products
- Categories
- Product Details
- Shopping Cart
- Quantity Management
- Product Filtering

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project to htdocs.
4. Open phpMyAdmin.
5. Create/import the `e_commerce.sql` database.
6. Open the project using localhost.

## Database

The database SQL file is located in:

`database/e_commerce.sql`
